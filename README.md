# Brainy - викторина-бот для ВКонтакте

![CI](https://img.shields.io/badge/CI-passing-brightgreen)

Бот ведёт базу вопросов по разным темам, запускает викторины в чате, следит за очками участников и ведёт общий рейтинг. Можно играть как в быстром режиме (бот кидает вопрос — кто первый ответил, тот молодец), так и в турнирном.


## ✨ Возможности

- 🎮 **Быстрая викторина** — бот задаёт вопрос, первый ответивший получает очки
- 🏆 **Турнирный режим** — серия вопросов с регистрацией участников и подсчётом очков
- 📊 **Рейтинг игроков** — очки сохраняются и накапливаются
- 📚 **Категории вопросов** — история, география, наука, кино, спорт и другие
- 🌐 **Автообновление базы** — скрипт для пополнения вопросов из открытых источников
- 💾 **Персистентность** — данные сохраняются при перезапуске


### Как добавить бота в беседу

1. **Найдите бота** по названию сообщества в ВК или перейдите по ссылке: https://vk.com/club237614496
2. На странице сообщества нажмите кнопку **«Пригласить в беседу»** под аватаркой
3. Выберите нужный чат из списка, затем нажмите на чат и разрешите боту полный доступ к сообщениям чата
4. Готово! Напишите `/help` для списка команд
